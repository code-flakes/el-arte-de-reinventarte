# Imágenes

Las imágenes actuales son **fotografía de archivo de Unsplash**, colocadas para poder valorar
la dirección de arte. Se sustituyen por las reales manteniendo el mismo nombre de archivo:
las cuatro propuestas las toman automáticamente, sin tocar el HTML.

| Archivo | Uso | Formato recomendado |
|---|---|---|
| hero-villa.jpg | Portada a pantalla completa | horizontal, 2400×1600 |
| villa-1.jpg … villa-5.jpg | Galería de la villa | 1800px lado largo |
| dia-1.jpg, dia-2.jpg, dia-3.jpg | Programa día a día | 1600px lado largo |
| egda.jpg, fabiana.jpg, rosa.jpg | Retratos de las anfitrionas | vertical 3:4, 1400px |
| cierre.jpg | Cierre emocional | horizontal, 2400px |
| og.jpg | Vista previa al compartir | 1200×630 |

Optimiza a WebP o JPG por debajo de 300 KB cada una.

Las fotos de personas siguen siendo el punto débil: el stock disponible no encaja con el tono
de la marca. Lo ideal es usar material propio de Egda y de las anfitrionas.
