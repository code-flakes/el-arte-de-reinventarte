# Imágenes

Coloca aquí los archivos con estos nombres exactos y las tres propuestas los tomarán automáticamente.
Mientras falten, la landing muestra un marcador con el nombre esperado.

| Archivo | Uso | Formato recomendado |
|---|---|---|
| hero-villa.jpg | Portada, a pantalla completa | horizontal, 2400×1600 |
| villa-1.jpg … villa-5.jpg | Galería de la villa | vertical u horizontal, 1600px lado largo |
| dia-1.jpg, dia-2.jpg, dia-3.jpg | Programa día a día | vertical 4:5, 1400×1750 |
| egda.jpg, fabiana.jpg, rosa.jpg | Retratos de las anfitrionas | vertical 3:4, 1200×1600 |
| cierre.jpg | Cierre emocional (solo propuesta A) | horizontal, 2400×1400 |
| og.jpg | Vista previa al compartir | 1200×630 |

Optimiza a WebP o JPG por debajo de 300 KB cada una.
